StockPro | Inventory Management System 📦
A lightweight, professional-grade Inventory Management System (IMS)
built to streamline stock tracking, asset valuation, and vendor communication. This project was designed as a high-performance "Web App" with a focus on clean UX/UI and efficient data management.
 Key Features
Real-Time Dashboard: Instant insights into total stock count, overall inventory value (KES), and low-stock alerts:Users can Create, Read, Update (Edit), and Delete products seamlessly.
Smart Search & Filtering: Filter inventory by category or search by product name with instant table updates.
WhatsApp Integration: "One-Tap Order" button that generates pre-filled order messages for vendors.
Data Persistence: Uses `localStorage` to keep inventory data safe even after browser refreshes.
Responsive & Modern UI:Fully optimized for mobile and desktop with a built-in **Dark Mode** toggle.
Export Capabilities:Generate professional PDF reports or export data to CSV (Excel) for external analysis.

 Technical Stack
 Frontend: HTML5, CSS3 (Modern Flexbox/Grid)
Logic: JavaScript (ES6+)
 Data Storage:Browser LocalStorage API
Hosting:GitHub Pages

How to Use

1.Dashboard: Check your current stock status and total asset value at a glance.
2.  Add Item:Navigate to the "Add Item" tab to register new stock with price and quantity.
3. Inventory: Search for items, edit existing details if prices change, or delete old stock.
4.  Order:Click the "Order" button on any item to automatically open WhatsApp with an inquiry message.
